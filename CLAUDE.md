# OW Obsidian

This repository is the source for the `ow-obsidian` plugin. It supports Claude Code through `commands/` and `.claude-plugin/plugin.json`, and Codex through portable Agent Skills and `.codex-plugin/plugin.json`.

The plugin operates on the user's current Obsidian vault. This repository is never the vault merely because the plugin was installed from here.

Follow `AGENTS.md` for development and validation conventions.
