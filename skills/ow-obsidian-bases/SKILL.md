# OW Obsidian Bases

Read [references/bases.md](references/bases.md) before changing a `.base` file.

1. Resolve the vault and inspect the properties used by representative target notes.
2. Confirm the desired population, filters, columns, formulas, sorting, grouping, and view type.
3. Preserve existing views unless the user asks to replace them.
4. Write valid YAML and quote expressions containing special characters.
5. Save the `.base` file only in a locally established location or an explicit destination.
6. Report assumptions about the installed Obsidian version when syntax support may vary.
