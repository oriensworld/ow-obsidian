# Attribution

`ow-obsidian` is an independent, vault-agnostic adaptation inspired by:

- AgriciDaniel's [`claude-obsidian`](https://github.com/AgriciDaniel/claude-obsidian), MIT licensed, for its agent-maintained Obsidian wiki workflow.
- Andrej Karpathy's LLM Wiki pattern for persistent, compounding knowledge artifacts.

The OW skill surface maps the upstream project's wiki, ingest, query, lint, save, research, canvas, cleanup, Bases, Markdown, thinking, CLI, fold, mode, and retrieval capabilities. Workflow text and implementations are adapted for portable Agent Skills, Windows, Claude, Codex, and existing vault layouts.

No bundled Obsidian plugins or third-party CSS assets from the upstream project are included.
